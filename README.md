# 🌤️ Weather Monitor

A Python-based desktop application for monitoring local weather conditions and air quality.

The application allows users to record weather information, view weather history, monitor AQI, receive alerts and recommendations, generate reports, export data, and perform simple temperature prediction.

---

## ✨ Features

- 🔐 User login system
- 🌡️ Temperature monitoring
- 💧 Humidity monitoring
- 🌫️ Air Quality Index (AQI) monitoring
- 🌤️ Weather condition tracking
- ⚠️ Automatic weather alerts
- 💡 Weather-based recommendations
- 📝 Manual weather data entry
- 🤖 Sample weather data generation
- 📊 Weather history
- 🔎 Search records by city and date
- 🗑️ Delete individual records
- 🧹 Clear weather records
- 📄 Weather reports
- 📥 Export records to CSV
- 🕐 Live date and time display
- 🔮 Simple temperature prediction
- ✅ Input validation

---

## 🗄️ Database

The application uses **SQLite3** for local data storage.

Weather records contain information such as:

- City
- Temperature
- Humidity
- AQI
- Weather condition
- Alert
- Recommendation
- Date and time

---

## 📊 Weather & Air Quality Monitoring

The system monitors weather and air-quality information and provides status information based on the recorded values.

It can generate alerts and recommendations according to the weather conditions, AQI, temperature, and humidity.

---

## 📈 Reports & Data Export

The application provides:

- Weather history
- Weather analysis
- Search functionality
- CSV export
- Record management

---

## 🔮 Temperature Prediction

The application includes a simple temperature prediction feature based on previous temperature records for a selected city.
